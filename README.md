# Savoria 🍽️

Savoria is a full-stack food ordering web application designed to provide a simple and user-friendly online food ordering experience.

## 🚀 Live Demo

https://savoria-1.onrender.com

## ✨ Features

- User registration and login
- Dynamic food menu
- Food categories
- Shopping cart
- Order processing
- Admin dashboard
- Add, edit and delete dishes
- Order management
- Customer feedback management
- Responsive design for desktop and mobile

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite
- Git & GitHub

## 📌 Project Highlights

Savoria was developed as a web development project to demonstrate full-stack development, database management, user authentication and administrative functionality.
